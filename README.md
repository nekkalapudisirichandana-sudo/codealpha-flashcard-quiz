# CodeAlpha Flashcard Quiz App

## Task
CodeAlpha App Development Internship - Task 1: Flashcard Quiz App.

## Features
- Shows a question on the front of each flashcard.
- Shows the answer when the user clicks "Show Answer".
- Previous and Next navigation.
- Add new flashcards.
- Edit existing flashcards.
- Delete flashcards.
- Saves flashcards in browser localStorage.
- Simple and responsive user interface.

## How to Run
1. Download or extract the project.
2. Open `index.html` in a web browser.
3. Start creating and studying flashcards.

## Technologies
- HTML
- CSS
- JavaScript
- Browser localStorage
